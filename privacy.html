WeTally 隐私政策

最后更新日期：2026 年 3 月 13 日

WeTally（以下简称"本应用"）尊重并保护每一位用户的个人隐私。本隐私政策说明了本应用如何收集、使用和保护您的信息。请在使用本应用前仔细阅读。

一、我们收集的信息

1.1 我们不收集的信息

本应用不会收集以下信息：

  • 您的姓名、电话号码、电子邮箱地址或任何个人身份信息
  • 您的 Apple ID 或 iCloud 账户信息
  • 您的位置数据（地图功能中的地点信息由您主动输入，仅存储在您的设备和 iCloud 中）
  • 您的通讯录、照片库或其他设备内容
  • 您的账本名称、交易金额、分类名称或任何具体业务数据

1.2 您的业务数据（本地存储 + iCloud 同步）

您在本应用中输入的所有数据（账本、交易记录、分类、支付方式、交易平台、报销记录、储蓄目标等）：

  • 存储在您的设备本地数据库中
  • 通过 Apple iCloud 服务同步到您的其他设备（如果您已启用 iCloud 同步）
  • 仅您本人可以访问，开发者无法查看

1.3 匿名诊断数据

为了改善应用性能和稳定性，本应用会收集匿名的技术诊断数据，具体包括：

设备与应用信息：

  • 设备型号标识符（如 "iPhone16,1"）
  • iOS 系统版本（如 "18.3.2"）
  • 应用版本号和 Build 号

性能与稳定性数据（由 Apple MetricKit 框架提供）：

  • 崩溃报告（调用堆栈、异常类型）
  • 应用卡死报告（卡死时长、调用堆栈）
  • CPU 异常（累计 CPU 时间）
  • 磁盘写入异常（累计写入量）
  • 启动时间异常（启动耗时）
  • 每日性能指标汇总（内存峰值、帧率、CPU 使用、磁盘 IO 等）

数据库规模指纹（仅数量统计，不含具体内容）：

  • 账本总数、交易总数、分类总数、储蓄目标总数
  • 应用内存占用、设备剩余存储空间、设备热状态

以上诊断数据均为匿名的技术指标，不包含任何个人身份信息或具体业务数据内容，仅用于帮助我们改善应用的性能和稳定性。

二、信息使用

我们收集的匿名诊断数据仅用于以下目的：

  • 分析和修复应用崩溃与卡死问题
  • 监测和优化应用性能（启动速度、内存使用、帧率等）
  • 在用户遇到性能问题时，了解其数据量级，以便有针对性地优化

我们不会：

  • 将任何信息出售、出租或分享给第三方
  • 将诊断数据用于广告推送或用户画像
  • 将诊断数据与任何个人身份信息关联

三、数据存储与安全

3.1 业务数据

  • 存储在设备本地，使用 Apple Core Data 框架管理
  • 通过 Apple iCloud CloudKit 同步（使用 Apple 的端到端安全机制）
  • 数据存储在 Apple 运营的服务器上，受 Apple 隐私政策保护
  • 开发者无法访问您的私有 iCloud 数据

3.2 诊断数据

  • 存储在 Apple CloudKit 公共数据库中
  • 仅包含匿名技术指标，不包含任何可识别个人身份的信息
  • 仅开发者可通过 Apple CloudKit Dashboard 查看

3.3 第三方服务

本应用不使用任何第三方分析、广告或追踪 SDK。所有数据处理均通过 Apple 原生框架完成。

四、订阅服务

本应用提供会员订阅服务，会员功能包括但不限于：小组件支持、每日每周每月开销与收入的分析、每月预算的设置和交易搜索功能。会员功能的具体范围可能随版本更新进行调整。

本应用提供以下会员方案（价格可能随时间调整，以 App Store 内显示的实际价格为准）：

包月会员（自动续订）

  • 订阅周期：1 个月
  • 付款：用户确认购买并付款后记入 iTunes 账户
  • 取消续订：请在当前订阅到期 24 小时以前，在 iPhone 的「设置 → Apple ID → 订阅」中关闭自动续订
  • 续订：Apple 账户会在到期前 24 小时内扣款，扣款成功后订阅周期顺延一个月

包季会员（自动续订）

  • 订阅周期：3 个月
  • 付款、取消续订、续订规则同包月会员（扣款成功后顺延三个月）

包年会员（自动续订）

  • 订阅周期：1 年
  • 付款、取消续订、续订规则同包月会员（扣款成功后顺延一年）

永久会员（一次性购买）

  • 一次性买断，永久解锁全部会员功能
  • 无需续订，购买后终身有效

所有订阅和购买均通过 Apple App Store 内购（In-App Purchase）完成，付款由 Apple 处理，开发者不会接触您的支付信息。不同地区的价格根据当地货币进行计算，可能因地区而异。

五、您的权利

  • 数据删除：您可以随时在应用内删除您的账本、交易记录等业务数据。删除操作会同步到 iCloud。
  • 停用 iCloud 同步：您可以在 iPhone 的「设置 → Apple ID → iCloud」中关闭本应用的 iCloud 同步。
  • 卸载应用：卸载本应用将删除设备上的所有本地数据。iCloud 中的数据可通过 Apple 的 iCloud 管理功能删除。

六、儿童隐私

本应用不针对 13 岁以下儿童设计，也不会故意收集儿童的个人信息。

七、隐私政策的更新

我们可能会不定期更新本隐私政策。更新后的政策将在应用内或以下链接发布：

  • 隐私政策：https://huangrunhua.github.io/TallyApp/privacy.html
  • 用户协议：Apple Standard EULA
